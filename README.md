# MyEngine — C++ Cross-Version Modding Framework

Высокопроизводительный C++ движок с поддержкой многопоточной асинхронной трансляции модов Java/NeoForge.

## Основные особенности
- **Multi-Process Architecture:** Изоляция процесса перевода от главного ядра игры.
- **Clock Syncing (Master-Slave):** Жесткая синхронизация тактов для предотвращения десинхронизации физики.
- **AOT Patching:** Локальная сборка кэша на ПК пользователя без нарушения EULA/Copyright.

## Авторские права и благодарности (Credits)
* **Create Mod:** Особая благодарность **simibubi** и всей команде разработки за оригинальный мод **Create**. Данный проект предоставляет лишь слой трансляции/оптимизации и не содержит оригинального кода мода.

## Разработчикам модов (Opt-Out Directive)
Если вы являетесь автором мода и не хотите, чтобы ваш мод транслировался нашей системой, добавьте в главный класс вашего мода строчку:
`//!NOT PROJECT <ИмяВашегоПроекта>`
Движок автоматически проигнорирует ваш мод при сборке кэша.
